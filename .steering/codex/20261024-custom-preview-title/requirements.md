# HTML タイトルの指定

## 変更する機能

CLI の `--title` オプションで、生成する HTML の `<title>` に任意の文字列を指定できるようにする。

## ユーザーストーリー

Markdown を開く人として、複数のプレビューをタブで見分けるため、タブに表示されるタイトルを自分で決めたい。

## 受け入れ条件

- `mdpeek --title "レビュー資料" file.md` が、`<title>レビュー資料</title>` を持つ HTML を生成して開く。
- 指定しない場合は従来どおりファイル名を `<title>` に使う。
- 指定した文字列は HTML として安全にエスケープする。
- 本文の上に表示するファイル名と元パスは維持する。
- 引数に誤りがある場合は HTML を生成しない。

## 制約事項

- 既存の静的 HTML と Chrome 起動方式を維持する。
- `--title` はファイル引数の前に指定する。
