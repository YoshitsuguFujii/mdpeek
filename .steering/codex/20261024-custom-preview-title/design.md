# 設計

## 実装アプローチ

CLI 引数を Go の `flag.FlagSet` で読み、タイトル指定値を描画へ渡す。指定がない場合だけファイル名をタイトルとして使う。HTML テンプレートにはタブのタイトルと画面上のファイル名を別々に渡す。

## 変更するコンポーネント

- `main.go`: CLI 引数の解析、描画引数、テンプレートの表示値。
- `main_test.go`: CLI から生成した HTML のタイトル、エスケープ、既定値、誤った引数を検証。
- `README.md`: `--title` の使用例と既定値。

## データ構造の変更

永続データの変更なし。描画用データに画面表示用ファイル名を追加する。

## 影響範囲

指定時は Chrome のタブ名が変わる。既存の引数形式と未指定時の表示は維持する。`html/template` による自動エスケープを使い、入力文字列が HTML 要素にならないようにする。追加の外部通信や保存形式変更はない。
